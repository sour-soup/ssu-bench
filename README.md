# SSU-Bench

REST API сервис для биржи задач (task marketplace), где заказчики публикуют задачи, а исполнители подают заявки на их выполнение.

## Технологический стек

| Компонент        | Технология              |
|------------------|-------------------------|
| Язык             | Java 25                 |
| Фреймворк        | Spring Boot 4.0.6       |
| База данных      | PostgreSQL 18.3         |
| Миграции         | Liquibase               |
| API документация | OpenAPI 3.1 + SpringDoc |
| Аутентификация   | JWT                     |
| Сборка           | Gradle                  |

## Функциональность

### Роли пользователей

| Роль         | Возможности                                                                              |
|--------------|------------------------------------------------------------------------------------------|
| **CUSTOMER** | Создание задач, отмена задач, просмотр заявок, принятие заявок, подтверждение выполнения |
| **EXECUTOR** | Просмотр задач, подача заявок, отметка о выполнении                                      |
| **ADMIN**    | Просмотр пользователей, блокировка/разблокировка                                         |

### Основные сценарии

1. **Заказчик** создаёт задачу с описанием и вознаграждением
2. **Исполнители** подают заявки на выполнение
3. **Заказчик** выбирает исполнителя и принимает заявку (средства блокируются на счёте)
4. **Исполнитель** выполняет задачу и отмечает её завершённой
5. **Заказчик** подтверждает выполнение (средства перечисляются исполнителю)

## Запуск проекта

### Требования

- Java 25
- Docker (опционально, для PostgreSQL)

### Переменные окружения (пример)

```bash
POSTGRES_URI=jdbc:postgresql://localhost:5432/ssu_bench
POSTGRES_DB=ssu-bench
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_password
JWT_SECRET=your_secret_key
```

Быстрый запуск

```bash
docker compose up
```
